# Parity-check matrix H -- Hsiao SEC-DED (72,64)

Generated by `model/gen_rtl.py`. Systematic form `H = [ A | I_8 ]`:
columns 0..63 are data bits, columns 64..71 are check bits.

A codeword satisfies `H . c = 0 (mod 2)`. The syndrome of a received
word is `S = H . r = H . e`, which depends only on the error, so a
single flip at position p yields S = column p.

## Properties

| property | value | why it matters |
|---|---|---|
| columns nonzero | True | a flip is always visible |
| columns odd weight | True | syndrome parity = error count mod 2 (free DED) |
| columns distinct | True | a flip is unambiguously locatable |
| d_min | 4 | correct 1 **and** detect 2 simultaneously |
| column weights | {1: 8, 3: 56, 5: 8} | minimum legal total weight = minimum XOR area |
| row weights | all 27 | balanced -> shortest critical path |
| total weight | 216 | total XOR gate inputs |
